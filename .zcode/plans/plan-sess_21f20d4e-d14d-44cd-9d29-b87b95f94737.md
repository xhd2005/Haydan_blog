# 足迹页重设计方案 —— 「星河漫游 · 纸上远行」v3

已批准方向不变（混合式两幕结构 × 航空HUD×手账融合 × 跟随站点主题 × 入场动画编排），按新反馈调整地球图层与宇宙背景。

## 本轮新增调整

**1. 晨昏线处理（GoogleEarthGlobeView）**
- 删除金色晨昏描边线（`terminator-twilight-core` 细线与生硬的 golden line 观感）；
- 保留并强化「晨昏效果」：夜半球阴影面改为柔和的昼夜过渡晕染——用更宽、更模糊的暮光晕层（大幅 blur + 降透明度）贴着晨昏边界做氛围散射，深色模式下呈现自然的昼夜软过渡，浅色模式下减至极淡；
- 保留并优化夜半球城市灯火（暖金光晕 + 白炽内芯双层圆点，深色醒目、浅色减淡）。

**2. 宇宙背景美化（JourneyStarfieldCanvas 升级）**
- 新增银河带：沿倾斜银河平面聚集的高密度恒星带（数千颗微星 + 尘埃暗隙），营造真实银河纵深感；
- 多彩星云：emerald/teal/violet 多色系星云微粒场，additive 混合发光，缓慢漂移呼吸；
- 恒星层次升级：按天体色温分布（蓝白/白/黄/橙红）+ 三档尺寸 + 独立闪烁相位，前景亮星带十字衍射光芒；
- 流星与鼠标视差保留并调优；
- 浅色模式下星场大幅减淡为「晨曦微星」，配合 CSS 晨蓝渐变天空 + 柔光云晕。

## 维持已批准的其余设计

- **入场编排**：开屏长镜头重排（航线牵引 SVG 绘制 + 手写标语 + 幕帘式退场，约 3.2s，尊重 reduced-motion）→ 地球下潜 → 面板错峰入场（索引滑入/指示器落位/工具栏淡入/滚动引导升起）→ 登机牌 spring + VisaStamp 盖章动效 → 画卷 count-up + RevealStagger 级联。
- **两幕结构**：第一幕 100svh 地球舞台（面板减法：去遥测HUD/芯片坞/scrubber，航站索引 300px，剧场模式 fixed inset-0 且槽位占位防跳动）；第二幕白瓷画卷（数据缎带/年份时间线/MagazineCard 网格/筛选/手写 CTA）；浮窗 fixed→absolute 随页滚走。
- **双主题**：深色夜航星河 / 浅色晨曦航线（MapLibre 浅色分支：大气提亮、晨蓝天空、raster 加饱和）。
