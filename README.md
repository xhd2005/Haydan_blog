## 📖 理念与设计美学

**Hayden Xue Digital Garden** 是一个面向长期心智资产沉淀的高颜值, 现代化全栈个人站点. 项目打破了传统博客“流水账式文章堆砌”的静态局限, 融合了**数字花园（Digital Garden）演进哲学**与**航海探索（Voyage Odyssey）空间隐喻**：

- 🎨 **双主题深度景深体系 (Theme Depth Hierarchy)**：
  - **白瓷凝脂模式 (`#fbfbfd`)**：以雪白白瓷为基底, 微磨砂白瓷卡片悬浮, 配合细腻的多级阴影与冷灰边框, 呈现如纸质出版物般的温润质感；
  - **曜石深空模式 (`#050608`)**：以黑曜石微晶深空为基底, 搭配 1px 极细微光边界、环境微光光晕与暗房大图灯箱, 营造赛博终端与时空漫游的极致深邃感.
- 🌱 **三态非线性知识演进 (Maturity Lifecycle)**：博文具备 `Sprout (萌芽)`、`Budding (成长)`、`Evergreen (常青)` 动态成熟度标签与双向拓扑关联, 呈现真正具有有机生命力的心智网络.
- ⚓ **100% 真实数据驱动 (Dynamic CMS Completeness)**：全站点标、3D 地球仪、心智手记、技术栈、背景巨幕与友链均无硬编码, 由现代化 CMS 控制台统一可视化管理与持久化.

## ✨ 核心特性矩阵

### 1. 🌍 3D 航海游记与空间探索 (Voyage & Earth)
- **3D Google Earth / MapLibre 真实点标矩阵**：纯真实旅行足迹驱动, 支持高斯模糊视差、城市边界实时探寻, 点击点标直达游记详情；
- **登机牌机票与飞行遥测 HUD**：融合航海纪行与时空穿梭概念, 集成 35mm 胶片测光暗房灯箱与视觉海报.

### 2. 🧠 True RAG 纯内存向量外脑与多模型协作 (AI Neural Mind)
- **轻量原生 RAG 架构**：依托 **LangChain4j + ONNX 向量嵌入引擎**, 在 Spring Boot 启动期以 Java 21 / 25 虚拟线程在毫秒级内完成博文、足迹、编年史的语义切片与纯内存向量检索；
- **AI 智能伴读与写作副驾**：全局 Cmd+J 呼出伴读抽屉, 支持文章精读、代码深度解析、全站知识库精准检索与自动高亮出处；
- **未登录友好拦截**：未登录访客使用 AI 体验时无感唤起全站登录弹窗, 保障服务配额与系统安全.

### 3. ✨ 流动心智与成长度量衡 (Now & Timeline)
- **此时此刻 (Now Pulse)**：记录当前正在构建、研读、探索与思考的心智状态, 集成灵感微日志、氛围白噪音与音乐随身听；
- **时空纪元编年史 (Chronicle Archive)**：全动态展示个人技术成长里程碑与历史手稿.

### 4. 🎬 电影分幕式沉浸长卷 (Cinematic Scrollytelling)
- **关于页面四大剧幕**：序章（呼吸肖像与生命脉搏）➔ 回响（旷野沉思与胶片画廊）➔ 跃迁（动态时空纪元）➔ 终章（公理引言与交互终端）；
- **悬浮分幕导航坞 (Act Dock)**：实时跟踪滚动幕次, 支持平滑滚动跳转与键盘 Arrow 切幕.

### 5. 🛠️ 现代化 CMS 后台管理控制台
- 支持文章 Markdown 实时分栏预览编写、AI 双语翻译工坊、可视化全景巨幕视频配置；
- **站长头像与形象可视化管理**：支持本地图片一键直传对象存储、媒体库选图及实时圆形头像预览, 改动即刻刷新全网 ISR 静态缓存.

## 🚀 快速上手 (Quick Start)

### 1. 本地快速演练 (Local Development)

#### 运行前端工程
```bash
cd frontend
pnpm install
pnpm dev
# 打开浏览器访问 http://localhost:3000
```

#### 运行后端工程
```bash
cd backend
# 极速演练模式（使用内存 H2 数据库, 免配置直接启动）
mvn spring-boot:run -Dspring-boot.run.profiles=dev
# API 服务监听 http://localhost:8080
```

---

### 2. 腾讯云 / Linux 服务器生产一键部署 (Docker All-in-One)

博客已全面适配 Docker Compose 生产编排. 针对 4 核 4G 云主机配置了精细化的内存管控与 **2GB Swap** 分区防线, 全栈常态运行仅占用约 2.0GB 内存, 安全裕度超 40%.

#### 步骤 1：拉取工程与一键环境初始化
```bash
# 在云服务器上执行
git clone https://github.com/xhd2005/Haydan_blog.git /opt/hayden-blog
cd /opt/hayden-blog
sudo bash deploy/server-init.sh
```

#### 步骤 2：启动全栈服务容器
```bash
docker compose up -d --build
```

#### 步骤 3：常用运维命令
```bash
# 查看容器运行状态
docker compose ps

# 查看后端实时日志
docker compose logs -f backend

# 查看前端实时日志
docker compose logs -f frontend

# 一键重启博客全栈
docker compose restart
```

## 🔄 自动化持续集成 (GitHub Actions CI/CD)

项目在 `.github/workflows/deploy.yml` 中集成了创新的 **SSH 压缩管道流式直传** 自动化流水线：
- 代码推送到 `main` 分支时, 在 GitHub 免费云端 Runner 上快速编译前后端镜像；
- 通过 SSH 管道 `docker save | gzip -1 | ssh "gunzip | docker load"` 流式直传到你的云服务器, **零依赖第三方付费镜像仓库, 彻底规避国内拉取海外镜像的超时问题**；
- 零停机平滑滚动热重载容器.

只需在 GitHub 仓库 **Settings -> Secrets and variables -> Actions** 中配置 3 个密钥即可：
- `SERVER_HOST`: 服务器公网 IP（如 `49.233.166.212`）
- `SERVER_USER`: 服务器登录用户名（如 `ubuntu`）
- `SERVER_SSH_KEY`: 服务器专属部署私钥完整文本
